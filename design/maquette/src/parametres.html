Paramètres

Gérez votre compte, vos préférences et la configuration de DropLink.

Nom complet

Le nom affiché dans votre espace, et ses initiales.

AN

80 caractères maximum.

Adresse e-mail

L’adresse de connexion de votre compte. Un lien de confirmation part vers la nouvelle adresse.

Votre adresse ne change qu'une fois ce lien suivi.

Mot de passe

Changer le mot de passe déconnecte vos autres appareils.

Vous vous connectez avec Google ? Définissez d'abord un mot de passe avec « Mot de passe oublié ».

12 caractères minimum. Une phrase vaut mieux qu'un mot compliqué.

Supprimer le compte

Cette action est définitive. Votre compte, vos commandes, vos envois et vos liens clients seront supprimés et ne pourront pas être restaurés.

Seules votre adresse e-mail et les dates d'inscription et de suppression sont conservées un an, comme la loi l'impose à un hébergeur, puis effacées.

Langue

Personnalisez votre expérience sur DropLink.

La langue des pages que voient vos clients se règle dans Ma marque.

Authentification à deux facteurs (2FA)

Sécurisez votre compte avec un code de vérification.

Activée

Scannez ce code avec votre application d'authentification, puis saisissez le code qu'elle affiche.

Clé de secours JBSW Y3DP EHPK 3PXP Q7NL OZ4V Notez-la en lieu sûr : c'est la seule façon de retrouver l'accès si vous perdez votre appareil.
